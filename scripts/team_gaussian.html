📊 Rozkład Gaussa - Zespół Journey Planner

Analiza produktywności i umiejętności 3-osobowego zespołu studenckiego

Backend Developer

🔧 Specjalista Backend

Zakres: API RESTful, bazy danych, logika biznesowa

Technologie: Node.js, Express, TypeScript, PostgreSQL

Odpowiedzialności:

  • Projektowanie struktury bazy danych
  • Implementacja endpointów API
  • Logika kalkulacji kosztów
  • Testy jednostkowe

Parametry Gaussa:

μ (średnia) = 70

σ (odchylenie) = 15

Max wydajność: ~85-100%

Frontend Developer

🎨 Specjalista Frontend

Zakres: Interfejs użytkownika, UX/UI, mapy

Technologie: React, TypeScript, Tailwind CSS, Leaflet

Odpowiedzialności:

  • Projektowanie wireframes
  • Implementacja komponentów React
  • Integracja z mapami (Leaflet)
  • Responsywny design

Parametry Gaussa:

μ (średnia) = 65

σ (odchylenie) = 12

Max wydajność: ~77-88%

Fullstack Developer / Integrator

🔗 Koordynator Integracji

Zakres: Integracja, testy, DevOps, dokumentacja

Technologie: Full stack, Docker, Git, Testing

Odpowiedzialności:

  • Koordynacja między frontend a backend
  • Testy end-to-end
  • Setup CI/CD
  • Dokumentacja projektu

Parametry Gaussa:

μ (średnia) = 60

σ (odchylenie) = 18

Max wydajność: ~78-96%

📈 Interpretacja Wykresu

Oś X: Poziom umiejętności/wydajności w projekcie (0-100%)

Oś Y: Prawdopodobieństwo/częstość występowania danego poziomu

Czerwona krzywa: Backend Developer - najwyższa średnia wydajność, stabilne umiejętności

Niebieska krzywa: Frontend Developer - dobra wydajność, umiarkowana zmienność

Żółta krzywa: Fullstack/Integrator - szeroki zakres kompetencji, większa zmienność

Wykres przedstawia rozkład normalny (Gaussa) wydajności każdego członka zespołu. Wyższy szczyt oznacza bardziej przewidywalną wydajność, szerszy rozkład - większą elastyczność i zmienność.
